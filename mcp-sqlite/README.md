# SQLite Output MCP Server

## Overview

The **SQLite Output MCP Server** is a lightweight MCP (Model Context Protocol) server designed to allow AI agents to persist and manage vulnerability findings in a local SQLite database.

Its primary purpose is to provide a controlled and secure interface for storing, updating, and retrieving vulnerability remediation records generated by automated workflows, security agents, or LLM-based security assistants.

The server intentionally exposes only a small set of predefined operations and prevents agents from executing arbitrary SQL statements, reducing the risk of accidental data corruption or unauthorized database manipulation.

---

## Key Features

- Stores vulnerability findings in a SQLite database.
- Automatically creates and maintains seven predefined tables:
  - Query1
  - Query2
  - Query3
  - Query4
  - Query5
  - Query6
  - Query7
- Supports:
  - Creating new findings
  - Updating specific editable fields
  - Listing findings
  - Reading complete records
- Uses parameterized SQL statements to prevent SQL injection.
- Restricts access to approved tables only.
- Does not expose:
  - Arbitrary SQL execution
  - DELETE operations
  - DDL operations (ALTER, DROP, CREATE by agents)

---

## Architecture

The server uses:

- Python
- SQLite
- MCP SDK (`mcp`)
- Standard I/O transport (stdio) for MCP communication

### Database

A custom database location can be configured through the environment variable:
SQLITE_OUTPUT_DB=/path/to/database.db

## Installation
Create python environment and install requirements.txt

```
python -m venv venv
pip install -r requirements.txt
```

Add the following in claude desktop config json:
```
    "sqlite-output": {
      "command": "C:/<your-path>/venv/Scripts/python.exe",
      "args": [
        "C:/<your-path>/mcp-sqlite3/server.py"
      ],
      "env": {
        "SQLITE_OUTPUT_DB": "C:/TEMP/mcp-sqlite3/agent_output.db"
      }
    }
```
